What began more than ten years ago as a fun side project for quickly presenting websites, mobile apps, and other digital products has become a sought-after tool relied upon by designers around the world.

To ensure that the application would not be overlooked in a crowded world of similar tools and would be able to expand into other categories, it was given a new distinctive visual style based on endless combinations of generated patterns inspired by lost signal stripes, which can be easily adapted to any surface.

All of this is then brought together by a new logo set in a custom-modified Inter font with swapped vowels, which turned an earlier compromise resulting from an already taken domain into a distinctive element that we used to build a fun system that automatically carries over into all main texts and messages, as well as motion design.
